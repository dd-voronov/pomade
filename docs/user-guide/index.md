# Pomade user guide

Pomade is a workspace for running coding agents across many projects: each project keeps its own
terminals, agents, documents and git view, and everything stays alive while you switch between
projects. This guide describes how to use it. How each feature is built is in
[`modules/`](../modules/index.md).

- **[Getting started](getting-started.md)** — choosing a workspace on first run, the parts of the window
  (Projects panel, icon strip, tab strip, panes), how projects, tabs and panels fit together, and what
  comes back after you quit.
- **[Projects](projects.md)** — organizing work in the Projects panel: the Workspace row, groups and projects,
  creating one (also from an existing folder), colors and icons, reordering, collapsing, deleting, and
  the unread counters.
- **[Files](files.md)** — the file tree: a project's roots and mounted folders, creating, renaming,
  moving and deleting, multi-select and drag and drop, go to path, reveal in Finder, symlinks, hidden
  folders.
- **[Tabs](tabs.md)** — opening tabs, preview tabs that the next click replaces, reordering and moving
  tabs to another project, renaming and coloring, closing and reopening, the dots and marks on a tab.
- **[Editor](editor.md)** — editing documents in the Live, Rendered, Raw and Table views: markdown,
  CSV tables, the Properties panel, links, find, spellcheck, saving, files that change on disk,
  recovering unsaved edits.
- **[Terminals and agents](terminals-and-agents.md)** — opening terminals and coding agents, which agents
  Pomade knows, unread tabs, copy and paste, clickable links, session history and resuming,
  attached terminals.
- **[Git](git.md)** — reviewing and landing work: marks in the tree, the Git panel, commit and push,
  history and comparisons, branches and worktrees, conflicts, the `pomade-git` command.
- **[Apps](apps.md)** — apps that run inside Pomade: installing and linking them, app tabs, side panels,
  the overlay, notices and badges, services that keep running, app commands on your PATH.
- **[Settings](settings.md)** — every setting, what it does and where it is kept; notices and the bell.
- **[Keyboard shortcuts](keyboard-shortcuts.md)** — every shortcut in one place.

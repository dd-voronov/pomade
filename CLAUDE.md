# Pomade — instructions for agents

Pomade is agentic dev and management environment and the platform that hosts the Pomade family of apps. Personal working rules come from the workspace `CLAUDE.md`, loaded automatically.

**Every session, before anything else, read:**

1. [`private/WORKING-AGREEMENT.md`](private/WORKING-AGREEMENT.md) — how we work, and which doc to read for
   which task. Read nothing else up front; it tells you what the task at hand needs.
2. [`private/SESSION-HANDOFF.md`](private/SESSION-HANDOFF.md) — work left hanging by the last session (often
   empty).

**A worker** — a sub-agent briefed by an orchestrating session — skips both: read only what your brief
names.
